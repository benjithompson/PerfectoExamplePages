OAuth 2.0 PKCE Flow

This demo walks through the complete Proof Key for Code Exchange authorization flow using real browser cryptography (SubtleCrypto) — no backend required. The "authorization server" is a second page on the same origin that simulates issuing an authorization code after login.

What will happen

①Generate a random code_verifier and compute code_challenge = BASE64URL(SHA-256(verifier))
②Redirect to the simulated Acme Auth server with the challenge (never the verifier)
③Log in with demo / Password1 — auth server issues an authorization code
④Back here: exchange the code + verifier for a token (PKCE verified with real SHA-256)
⑤View the decoded access token and the complete flow audit log
